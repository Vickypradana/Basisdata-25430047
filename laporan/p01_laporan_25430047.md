## 2. Ringkasan Dasar Teori
### ringkasan dasar teori

basis data itu kumpulan dari yang saling terhubung terus di simpen teratur agar mudah digunakan dan dikelolah bassi data bisa digunakan oleh beberapa pengguna atau apk secara langsung.yang ngolah basis adalah database manegement sistem (dbms) ,perangkat lunak yg mengatur menyimpan , mengolah, dan akses data.


mariadb menggunakan sistem client-server.di bagian server ada proses mariadbd yang berjalan di latar belakang dan menerima permintaan melalui port tcp 3306. untuk terhubung ke server mariadb, client bisa menggunakan mysql cli atau phpmyadmin. client mengirim perintah sql ke server, lalu server memprosesnya dan mengirimkan hasil atau pesan error kembali ke client.

mysql cli digunakan lewat terminal atau command prompt, sedangkan phpmyadmin digunakan lewat web browser dengan tampilan grafis. walaupun cara pakainya berbeda, keduanya sama-sama berfungsi sebagai client untuk mengirim perintah dan mengelola database di server mariadb.

xampp digunakan untuk mempermudah proses pengembangan karena sudah menyediakan beberapa komponen seperti apache, mariadb, php, dan phpmyadmin dalam satu paket. jadi, pengguna tidak perlu memasang komponen tersebut satu per satu.

untuk mengakses mariadb lewat cli, pengguna bisa membuka command prompt atau terminal lalu menjalankan perintah yang sesuai. sedangkan untuk phpmyadmin, pengguna cukup membukanya melalui web browser. akses mariadb diatur berdasarkan akun pengguna, seperti root@localhost dan root@127.0.0.1. akun root memiliki hak akses yang tinggi dan pada beberapa instalasi awal bisa saja belum menggunakan password, sehingga perlu diamankan dengan password.

git digunakan untuk mencatat dan mengelola perubahan pada file melalui commit. alur kerja git biasanya terdiri dari working directory, staging area, repository lokal, dan repository jarak jauh seperti github. perubahan file dimasukkan ke staging area dengan `git add`, disimpan ke repository lokal dengan `git commit`, lalu dikirim ke github menggunakan `git push`.

beberapa perintah yang digunakan dalam praktikum yaitu `mysql -u root -p` untuk masuk ke mariadb sebagai root, `select version()` untuk melihat versi mariadb, `show databases` untuk melihat database yang tersedia, `create database` untuk membuat database baru, `create user` untuk membuat akun baru, `grant` untuk memberikan hak akses, dan `exit` untuk keluar dari mariadb. sedangkan pada git digunakan perintah `git init` untuk membuat repository lokal, `git add` untuk memasukkan perubahan ke staging area, `git commit` untuk mencatat perubahan, dan `git push` untuk mengirim perubahan ke repository github.
