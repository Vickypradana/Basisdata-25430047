basis data adalah kumpulan data yang saling berhubungan dan disimpan secara teratur agar lebih mudah digunakan dan dikelola. basis data juga bisa digunakan oleh beberapa pengguna atau aplikasi secara bersamaan. untuk mengelola basis data, digunakan database management system (dbms), yaitu perangkat lunak yang membantu mengatur proses penyimpanan, pengolahan, dan akses data.

dbms diperlukan karena aplikasi tidak harus mengatur sendiri semua proses penyimpanan dan pengelolaan data. dbms dapat membantu mengatur akses dari beberapa pengguna secara bersamaan, menjaga data tetap konsisten, dan mengatur hak akses pengguna. fungsi utama dbms mencakup proses menambah, mengubah, menghapus, dan mengambil data. selain itu, dbms juga dapat menjaga integritas data agar data yang dimasukkan sesuai dengan aturan, mendukung penggunaan database oleh banyak pengguna, serta menjaga keamanan data dengan membatasi pengguna yang boleh mengaksesnya.

mariadb menggunakan arsitektur client-server. pada bagian server terdapat proses mariadbd yang berjalan di latar belakang dan menerima permintaan melalui port tcp 3306. untuk berkomunikasi dengan server mariadb, pengguna dapat menggunakan beberapa client seperti mysql cli dan phpmyadmin. client akan mengirimkan perintah sql ke server, kemudian server memproses perintah tersebut dan mengirimkan hasil atau pesan kesalahan kembali kepada client.

mysql cli digunakan melalui terminal atau command prompt, sedangkan phpmyadmin digunakan melalui web browser dengan tampilan grafis. walaupun cara penggunaannya berbeda, keduanya memiliki fungsi yang sama, yaitu sebagai client untuk mengirimkan perintah ke server mariadb dan mengelola basis data.

xampp digunakan untuk mempermudah proses pengembangan karena sudah menyediakan beberapa komponen yang dibutuhkan, seperti apache, mariadb, php, dan phpmyadmin. dengan xampp, pengguna tidak perlu memasang setiap komponen tersebut secara terpisah sehingga proses instalasi dan penggunaannya menjadi lebih praktis.

untuk mengakses mariadb melalui cli, pengguna dapat membuka command prompt atau terminal kemudian menjalankan perintah yang sesuai. sedangkan untuk mengakses mariadb melalui phpmyadmin, pengguna cukup membuka phpmyadmin melalui web browser. pengaturan akses pada mariadb dilakukan berdasarkan akun pengguna. pada beberapa instalasi terdapat akun seperti root@localhost dan root@127.0.0.1. akun root memiliki hak akses yang tinggi dan pada instalasi tertentu bisa saja belum menggunakan password, sehingga perlu diamankan dengan memberikan password.

git digunakan sebagai alat untuk mengontrol versi dan mencatat setiap perubahan pada file dalam bentuk commit. alur kerja git biasanya terdiri dari direktori kerja, staging area, repository lokal, dan repository jarak jauh seperti github. perubahan pada file dapat dimasukkan ke staging area menggunakan perintah git add, kemudian dicatat ke repository lokal menggunakan git commit, dan dikirim ke repository github menggunakan git push.

beberapa perintah yang digunakan dalam praktikum antara lain mysql -u root -p untuk masuk ke server mariadb menggunakan akun root sekaligus meminta password, select version() untuk melihat versi mariadb, show databases untuk melihat database yang tersedia, create database untuk membuat database baru, create user untuk membuat pengguna baru, grant untuk memberikan hak akses, dan exit untuk keluar dari mariadb. pada git, perintah yang digunakan antara lain git init untuk membuat repository lokal, git add untuk memasukkan perubahan ke staging area, git commit untuk mencatat perubahan, dan git push untuk mengirim perubahan ke repository github.
